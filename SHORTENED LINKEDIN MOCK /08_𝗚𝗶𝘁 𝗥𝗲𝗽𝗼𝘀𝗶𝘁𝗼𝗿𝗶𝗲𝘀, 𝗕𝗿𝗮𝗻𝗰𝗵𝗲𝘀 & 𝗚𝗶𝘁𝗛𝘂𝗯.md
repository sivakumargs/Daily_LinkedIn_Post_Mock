💻 𝗨𝘀𝗲𝗳𝘂𝗹 𝗰𝗼𝗺𝗺𝗮𝗻𝗱𝘀

git clone <repository-url>

→ Downloads a repository.

git branch

→ Lists local branches.

git switch -c feature/update-readme

→ Creates and switches to a branch.

git switch main

→ Switches to main.

git merge feature/update-readme

→ Merges the feature branch into the current branch.

git remote -v

→ Shows remote repositories.

git push -u origin main

→ Pushes main to the remote repository.

Code reviews also help identify security issues before changes are merged.
