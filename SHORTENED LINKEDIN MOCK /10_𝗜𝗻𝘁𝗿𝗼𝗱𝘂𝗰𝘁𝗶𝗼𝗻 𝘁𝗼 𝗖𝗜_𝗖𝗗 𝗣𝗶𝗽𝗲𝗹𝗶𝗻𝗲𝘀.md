git status

→ Checks repository status.

git add .

→ Stages changes in the current directory and its subdirectories.

git commit -m "Add application changes"

→ Records staged changes.

git push origin main

→ Pushes the local main branch to the remote repository.

⚙️ 𝗪𝗵𝗲𝗿𝗲 𝗱𝗼𝗲𝘀 𝗚𝗶𝘁𝗛𝘂𝗯 𝗔𝗰𝘁𝗶𝗼𝗻𝘀 𝗳𝗶𝘁?

GitHub Actions lets me automate workflows using YAML files.

Example location:

.github/workflows/ci.yml

A workflow can run when code is pushed or a Pull Request is opened or updated.

It can execute tests, build applications, and run security scans.

CI/CD helps teams detect problems earlier, reduce manual work, and deliver software consistently.

DevSecOps adds security checks such as dependency scanning and code analysis throughout the pipeline.
