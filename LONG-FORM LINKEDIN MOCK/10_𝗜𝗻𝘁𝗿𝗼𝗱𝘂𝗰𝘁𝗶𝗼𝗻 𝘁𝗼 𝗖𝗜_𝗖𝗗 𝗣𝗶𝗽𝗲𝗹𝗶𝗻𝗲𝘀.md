💻 𝗨𝘀𝗲𝗳𝘂𝗹 𝗚𝗶𝘁 𝗰𝗼𝗺𝗺𝗮𝗻𝗱𝘀

git status

Checks the current state of the repository.

git add .

Stages changes in the current directory and its subdirectories. Review the files before staging.

git commit -m "Add application changes"

Records the staged changes.

git push origin main

Pushes the local main branch to the remote repository.

When connected to a configured CI/CD workflow, a push can trigger automated jobs.

⚙️ 𝗔 𝘀𝗶𝗺𝗽𝗹𝗲 𝗖𝗜 𝗲𝘅𝗮𝗺𝗽𝗹𝗲

GitHub Actions allows me to define automated workflows using YAML files.

Example file:

.github/workflows/ci.yml

name: Basic CI

on:
  push:
  pull_request:

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Confirm workflow runs
        run: echo "CI pipeline started successfully!"

This beginner-friendly workflow runs when code is pushed or a Pull Request is opened or updated.

It checks out the repository and executes a simple command.

Real projects can add build steps, tests, dependency checks, and security scans.

🛡️ 𝗪𝗵𝘆 𝗱𝗼𝗲𝘀 𝘁𝗵𝗶𝘀 𝗺𝗮𝘁𝘁𝗲𝗿 𝗳𝗼𝗿 𝗗𝗲𝘃𝗦𝗲𝗰𝗢𝗽𝘀?

DevSecOps is about integrating security into the software delivery process.

CI/CD helps teams:

🔹 Detect bugs earlier through automated tests.

🔹 Scan dependencies for known vulnerabilities.

🔹 Check code for potential security issues.

🔹 Reduce repetitive manual work.

🔹 Deliver software more consistently.

🔹 Apply security checks before deployment.

Automation alone does not guarantee security. The pipeline must include appropriate checks, protected credentials, and controlled deployment permissions.
